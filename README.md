# ฟุตซอลลีก

แอปผลกีฬามือถือสำหรับลีกอำเภอบาเจาะ (8 อปท.) — Phase A: UI + mock data

## รันท้องถิ่น

```bash
npm install
npm run dev
```

## สแตกที่วางแผน

- Frontend: React + Vite + TypeScript (เฟสนี้)
- Hosting: Vercel
- Backend/DB: Supabase (เฟสถัดไป + Admin)
- Repo: GitHub
